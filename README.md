# DevTasks

**Gerenciador de Tarefas desenvolvido em linguagem C.**

## Sobre o projeto

O DevTasks é um programa de gerenciamento de tarefas desenvolvido como atividade acadêmica, com o objetivo de aplicar conceitos de programação em C e utilização do Git e GitHub para controle de versões e colaboração.

## Funcionalidades

- Adicionar tarefas;
- Listar tarefas cadastradas;
- Concluir tarefas;
- Remover tarefas.

## Tecnologias utilizadas

- Linguagem C;
- GCC (compilador);
- Visual Studio Code;
- Git;
- GitHub.

## Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/spHiago/DevTasks.git
   ```

2. Entre na pasta do projeto.

3. Compile o programa:
   ```bash
   gcc main.c -o DevTasks.exe
   ```

4. Execute:
   ```powershell
   .\DevTasks.exe
   ```
